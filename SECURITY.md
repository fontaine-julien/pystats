# Politique de sécurité

## Versions maintenues

Les correctifs de sécurité sont intégrés à la version courante de PyStats, actuellement **2.6.0**. Si vous utilisez une version antérieure, vérifiez si le problème se reproduit avec la version courante.

## Signaler une vulnérabilité

Pour signaler une faille, utilisez le bouton **Report a vulnerability** dans les [avis de sécurité de PyStats](https://github.com/fontaine-julien/pystats/security/advisories). Le signalement est transmis en privé.

Indiquez la version de PyStats, votre système d’exploitation, les étapes pour reproduire le problème et son impact possible. Utilisez des données fictives dans vos exemples et retirez toute donnée personnelle, notamment celles des élèves.

J’examinerai les signalements selon mes disponibilités et je vous répondrai dans le fil privé. Si la vulnérabilité est confirmée, nous pourrons y convenir des suites à donner.
